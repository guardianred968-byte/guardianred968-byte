# GUARDIAN RED  Offensive Security & AppSec

**Segurança ofensiva • Pentest Web • AppSec • Pesquisa de Vulnerabilidades**

Bem-vindo ao meu espaço dedicado à segurança cibernética. Este perfil reúne projetos técnicos, pesquisas, ferramentas e análises voltadas à identificação de vulnerabilidades, avaliação de riscos e fortalecimento da segurança de aplicações e sistemas.

## Áreas de atuação

- **Web Application Security:** análise de aplicações web, APIs e mecanismos de autenticação.
- **Pentest & Red Team:** testes de segurança controlados e avaliação de superfícies de ataque.
- **Vulnerability Research:** identificação, análise e documentação de falhas de segurança.
- **Secure Code Review:** revisão de código, dependências e configurações.
- **AppSec & Vibe Coding:** auditoria de aplicações desenvolvidas com IA, frameworks e bibliotecas externas.
- **Security Automation:** scripts e ferramentas para análise e validação de segurança.

## Tecnologias e ferramentas

Linux • Kali Linux • Burp Suite • OWASP ZAP • Nmap • Semgrep • npm audit • OSV-Scanner • Python • JavaScript

*Ferramentas utilizadas conforme os requisitos de cada projeto.*

## Projetos e pesquisas

Este perfil é destinado à publicação de:

- Ferramentas e scripts de segurança.
- Laboratórios e provas de conceito controladas.
- Relatórios técnicos e estudos de vulnerabilidades.
- Auditorias de código e análise de dependências.
- Documentação de metodologias e correções.

## Princípios

A segurança deve ser orientada por evidências, análise técnica e documentação reproduzível. Os testes são realizados em ambientes próprios ou autorizados, respeitando os limites legais e a divulgação responsável de vulnerabilidades.
